IBM Bob's Prompt Templates & Workflow Orchestration — Step by Step

⟳ Load Pipeline IBM Bob Bob built the HAR parser that imports ISC data past IBM w3id auth. No prompt needed — pure orchestration.
⬡ Score Deals Bob prompt → granite-13b Bob's scoring prompt template sends each opportunity's fields to ibm/granite-13b-instruct-v2 via IBM watsonx.ai. Returns 0–100 score + tier.
✍ GM Narrative Bob prompt → llama-3-70b Bob's narrative prompt template sends filtered pipeline context to meta-llama/llama-3-70b-instruct. Returns meeting-ready prose + bullets.
⇄ What Changed Bob prompt → granite-3-8b Bob's delta prompt template sends week-over-week diff to ibm/granite-3-8b-instruct. Returns change narrative for PPT slide.
📋 Custom Report IBM Bob + pptxgenjs Bob's Column Picker template generates a user-defined IBM-branded PPTX with chosen columns, drag-reordered, in seconds.
Bob's prompt orchestration replaces human toil: Before this app, a Sales VP spent 20–30 minutes writing a GM narrative from memory, 30 minutes hand-scoring deals, 20 minutes comparing last week's pipeline. Bob's prompt templates do all three automatically, sequenced, every week — so the VP spends those 75 minutes in front of customers instead.

Why AI Assists — But Humans Remain in the Loop

The honest design thesis: A Sales VP like Dushyant Patel carries 20 years of customer knowledge that exists nowhere in ISC — not in any opportunity field, not in any Next Steps note, not in any forecast category. Which deal is real vs. pipeline theater is a judgment call that lives in a human's head. This application never tries to replace that judgment. IBM Bob's prompts surface the data signals; the VP applies the instinct. The AI handles the 90 minutes of mechanical prep so the human can spend 90 minutes on the relationships and decisions that only a human can make.
